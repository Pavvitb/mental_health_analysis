# Mental Health Analysis

A data analysis project focused on exploring mental health trends and insights using Python and Jupyter Notebook.

---

## Project Overview

This project performs exploratory data analysis (EDA) on mental health-related datasets to identify patterns, trends, and correlations.

The notebook includes:
- Data cleaning
- Data preprocessing
- Exploratory Data Analysis
- Data visualization
- Insight generation

---

## Tech Stack

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
